# Simplified-3D
It is a simple, intuitive 3D modeler built using the Rust programming language. The models are compatible with other modeling software like Blender (verified) and game engines such as Godot, Unity, or Fyrox (unverified, but I have faith).

"I just want to model, not make my life complicated."

This phrase captures what I aim to achieve with this project: a modeler that is easy to use and understand from the very first moment. Since many current modeling tools are extremely complex, I am taking the opposite approach. (To clarify: I have no intention of competing with major tools like Blender; I simply want newcomers to have a pleasant modeling experience—after all, I am one of them myself.)

It is quite simple for now, but I plan to improve it over time. I would be very grateful for any contributions or brainstorming; however, if you do have ideas, please ask yourself these questions: Is it truly necessary? Is it easy—or at least reasonably easy—to use?

Thank you for reading.
